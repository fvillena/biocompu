Se le solicita ajustar (o entrenar) un modelo de aprendizaje automático para predecir etiquetas sobre ejemplos nuevos.

En particular, trabajaremos con el \textit{Pima Indians Diabetes Dataset}. Este conjunto de datos tiene como objetivo predecir si un paciente tiene o no tiene diabetes en base a una serie de características. La muestra consiste en datos de mujeres de al menos 21 años de descendencia indígena del grupo \textit{Pima}. Específicamente, existen varios atributos clínicos y una variable objetivo \textit{Outcome}. Esta columna \textit{Outcome} alcanza un valor igual a 1 cuando la paciente posee  diabetes, mientras que es 0 cuando no posee la enfermedad.

Deben realizar un flujo clásico al momento de crear modelos de aprendizaje automático.

El conjunto de datos se encuentra en la siguiente dirección:

\begin{center}
    \url{https://raw.githubusercontent.com/fvillena/biocompu/2023/data/diabetes.csv}
\end{center}

\section*{Preguntas}

Responda las siguientes preguntas en un \textit{Jupyter Notebook} con código desarrollado en el lenguaje de programación Python.

\begin{enumerate}
    \item ¿Cuántas instancias y cuántos atributos contiene el conjunto de datos?
    \item ¿Cuál es la distribución de clases en la variable objetivo \textit{Outcome}?
    \item ¿Cuántos pacientes mayores a 40 años padecen de diabetes?
    \item Separe el conjunto de datos en un subconjunto de entrenamiento y uno de prueba.
    \item Ajuste un modelo de clasificación sobre el subconjunto de entrenamiento.
    \item Prediga utilizando el modelo ajustado (el que ajustó sobre el conjunto de entrenamiento), sobre el subconjunto de prueba.
    \item Calcule la métrica de \textit{accuracy} del su modelo, sobre el conjunto de prueba.
\end{enumerate}
